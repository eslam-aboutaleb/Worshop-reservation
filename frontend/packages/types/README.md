# @ws/types

TypeScript surface for the workshop-reservation API.

## Layout

| File | Origin | Edit? |
|------|--------|-------|
| `src/openapi.d.ts` | Generated by `openapi-typescript` from the backend's OpenAPI document | **Never hand-edit** — regenerate |
| `src/index.ts` | Hand-written entry: re-exports the generated types under the app's short names (`Workshop`, `Reservation`, …) plus the hand-maintained `SSEEvent` and `ApiErrorCode` | Yes |

## Regenerating

With the backend running on `localhost:8000`:

```sh
npm run generate:types
```

(fetches `http://localhost:8000/openapi.json` → `src/openapi.d.ts`).
Without a server, generate from a saved schema:

```sh
openapi-typescript /path/to/openapi.json -o src/openapi.d.ts
```

## Hand-maintained types

These are **not** in the OpenAPI document and live in `src/index.ts`:

- **`SSEEvent`** — payload published on the unauthenticated
  `/api/workshops/events` SSE stream. Sync with the event
  classes in `backend/libs/reservation/ws_reservation/events.py`.
- **`ApiErrorCode`** — the machine-readable codes in the
  `{"error": {"code", "message"}}` envelope. Sync with the
  `DomainError` subclasses in
  `backend/libs/core/ws_core/errors/__init__.py`.

When the backend adds a domain event or an error code, update
the matching union here in the same commit.

## Generated-shape differences

The generated types are the source of truth; resolve shape
differences at call sites, never by editing `openapi.d.ts`:

- Fields with server-side defaults (`status`, `booking_code`,
  `reviews`, `workshops`, `attendees`, `followers_count`, …)
  are **optional** in the generated types even though the
  backend always sends them. Consumers that require them
  should coalesce: `detail.reviews ?? []`.
- `format: "date-time"` / `format: "uuid"` fields are plain
  `string`s.
- Enum-like fields (`status`, `role`) are `string`, not
  string-literal unions, because the backend models them as
  plain `str`.

## Consumption

The package ships raw TypeScript (`main`/`exports` →
`./src/index.ts`); workspace consumers compile it in place.
